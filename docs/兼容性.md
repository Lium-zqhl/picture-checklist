# 兼容性与运行环境

版本：1.0.5。

## 支持目标与实测范围

| 项目 | 范围 |
| --- | --- |
| Windows 10 | 1903 及以后版本，x86 / x64 |
| Windows 11 | x64 |
| 运行库 | .NET Framework 4.8 或兼容的更新版本 |
| 权限 | 程序正常运行不要求管理员权限；清单目录需可写 |
| ARM64 | 尚未验收，不作兼容承诺 |
| macOS / Linux | 不支持原生运行 |

**开发机已实测的环境**：Windows 10 22H2，系统 build 19045，x64，.NET Framework 4.8.1。该结果不代表上述每个系统、架构和显示配置都已经实机验收。其他电脑、Windows 11、32 位 Windows、多屏混合缩放仍需相应环境的实际验证。

Windows 10 从 1903 开始的相关版本预装 .NET Framework 4.8；Windows 11 初始版本预装 4.8，较新版本预装 4.8.1。具体对应关系以 [Microsoft 的版本与依赖表](https://learn.microsoft.com/en-us/dotnet/framework/install/versions-and-dependencies) 为准。机器上的实际运行库状态仍应检查。

## “免安装”的含义

便携包完整解压后运行 `PictureChecklist.exe`，不需要本应用的安装器、账户或管理员启动。但它仍依赖系统运行库，不是包含整个 Windows / .NET 运行环境的自包含程序。

程序不把清单强制写入安装目录；新建清单时由用户选择资料文件夹。本机阅读设置保存在 `%LOCALAPPDATA%\PictureChecklist`。

## 环境检查

便携包中双击 `Check-Environment.cmd`，或在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check-environment.ps1
```

从源码检查时使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-environment.ps1
```

请依据检查输出定位 Windows 版本、架构或 .NET Framework 缺口。程序运行和运行库安装是两件事；运行库的安装权限由 Windows 和本机管理策略决定。

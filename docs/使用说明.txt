图文修改清单 / Picture Checklist 1.0.5

开始使用
完整解压便携包，双击 PictureChecklist.exe。
如需检查环境，可先双击 Check-Environment.cmd。
程序正常运行不需要管理员权限。清单应保存在你有写入权限的文件夹中。
更新时先关闭正在打开该清单的旧版程序，再启动新版。

创建与打开清单
首次启动可创建清单，填写名称并选择保存位置。
点击左上角当前清单名称，可新建、打开、切换、重命名或归档清单。
打开已有清单时选择该资料夹内的 checklist.json。
入门示例在 examples/getting-started，包含三条合成意见；可复制后体验。

粘贴截图，每图一条
截图后点击浮窗底部“粘贴截图，新建意见”输入区，按 Ctrl+V。
也可使用 Shift+Insert、右键粘贴、底部“选图片”，或把图片文件拖进浮窗。
每张图片独立建立一条意见；连续粘贴不会并入当前选择的条目。
一次选择或拖入多张图片，也按每图一条处理。
如输入区已有文字，该文字会随本批第一张图片保存为意见正文。
只添加文字时，输入后点“添加意见”。普通文字粘贴遵循文本框的光标位置。
图片导入到清单的 assets 文件夹；删除外面的临时截图后仍可使用。
支持 PNG、JPEG、BMP、GIF、TIFF；GIF 和多页 TIFF 显示首帧。

查看与完成
顶部编号用于快速跳转，带 ✓ 的编号表示已完成。
“全部 / 未完成 / 已完成”切换范围；点击“搜索”展开搜索框。
点击标题左侧完成框，立即打钩、卡片变浅绿色，统计与进度自动保存。
再次点击取消完成，重新列为未完成；详细状态记为“进行中”。
“未开始”和“进行中”都计入未完成。
展开备注可记录部分完成情况，也可标记要求待澄清。
个人确认并打钩即完成，不强制另走复核；需要复核时可重新打开。

图片放大
单击图片打开原图窗口。
“适合窗口”可放大小图；“100%”按原始像素比例显示。
使用 + / − 或 Ctrl+滚轮缩放；超出窗口时可滚动或拖动图片。Esc 关闭原图窗口。
新版兼容显示已知旧版粘贴产生的透明异常截图，原图文件保留不改。
放大不会补出低分辨率原截图中不存在的文字细节。

编辑、删除与拆分
点击卡片“编辑”，修改标题、意见、备注和补充说明后保存。
可在编辑窗口上移、下移或移入回收站。
显示编号随顺序变化，图片和进度始终跟随同一条意见。
“撤销”可撤回本次打开后的最近 24 次操作；文本框内 Ctrl+Z 撤销文字编辑。
历史多图条不自动拆开，以保留主动建立的多图意见。
需要拆开时，选择“编辑 → 拆为单图意见”：第一张保留在原条，其余各建一条，原文、备注及完成状态保留，整次拆分可撤销。
需要补图到同一条时，使用“编辑 → 为本条补图…”的明确入口。

更多功能
右上“更多”中包括：
- 整理与图片资料库：集中编辑、重排和管理图片关联；点“返回浮窗”回到日常界面。
- 回收站：恢复误删意见，重开后也能恢复。
- 导出完整备份 ZIP。
- 从 ZIP 恢复到新目录、从上一保存点恢复副本。
- 迁移旧版清单。
高级整理中的批量导入支持主动选择每图一条、多图一条、追加到已有意见或只放入图片资料库。

保存与草稿
勾选、图片添加和结构调整自动保存；备注等文字在停止输入约半秒后保存。
“已保存”表示文件已成功写入。
底部尚未点击“添加意见”的文字草稿在勾选、刷新界面或切换显示模式时保留。
正常关闭窗口或切换清单前，非空文字草稿先提交为文字意见，再尝试保存。
保存失败显示“保存失败 · 更改仍在窗口中”，可重试或另存当前内容与原图。
若关闭时仍保存失败，可继续留在窗口、导出副本后离开，或主动放弃未保存的修改。
异常退出不能保证恢复尚未提交或写入的输入。

资料与搬迁
清单资料保存在你选择的文件夹，主要包括 checklist.json、assets、backups；迁移清单另有 migration。
本机窗口位置与最近清单等设置保存在 %LOCALAPPDATA%\PictureChecklist。
搬迁时推荐先导出完整 ZIP，再在目标电脑恢复到新目录。
也可关闭清单后复制整个资料夹；不要只复制 checklist.json。
同一清单重复打开时会定位到已有窗口，避免两个程序同时写入。

旧格式迁移
选择“更多 → 迁移旧版清单…”，定位旧目录中的 tasks.json，核对摘要后选择新的保存位置。
迁移会复制原图，保留意见、旧编号、备注及完成记录；原目录保留。
该入口只接受约定的旧格式，不是任意 JSON 导入器：
- tasks.json 为数组；每条包含正整数且不重复的 id、title、actions 字符串数组、caution、needsConfirmation 布尔值，以及位于 images/ 下的 image 相对路径。
- images 文件夹中保留对应原图，不应混入未关联文件。
- progress.json 可选；其 version 为 1，items 以旧编号字符串为键，每项含 done、clarified、note、updated。
- 没有 progress.json 时按未开始导入。
- 不匹配、缺图或损坏时会明确提示，先修正副本后再迁移。

系统要求与已验证范围见 docs/兼容性.md。

清单库删除
每行“打开”左侧的“删除”只从本机清单库移除入口，不删除资料文件。确认后可在库底部“撤销删除”；连续删除可逐次撤销。关闭重开后入口仍隐藏，需通过“打开清单”选回checklist.json重新加入。
条目内的“移入回收站”用于删除单条意见，与整份清单的列表移除不同。

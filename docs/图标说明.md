# 程序图标

采用蓝色「叠页打钩」：两页意见资料与一个完成勾号。`src/app-logo.png` 是选定设计的透明 PNG，使用内置 imagegen 根据项目所有者选定的 A 稿改成蓝色；图标随本项目按 MIT 许可证提供。

`src/app.ico` 包含 16、20、24、32、40、48、64、128、256 像素九种尺寸。`scripts/build.ps1` 将其嵌入程序，资源管理器、快捷方式及默认窗口图标可使用同一图案。

更新 PNG 后，可用 Windows PowerShell 运行 `scripts/make-icon.ps1` 重新生成 ICO，再运行 `scripts/build.ps1`。转换脚本仅缩放并封装图标，不改变 Logo 内容。

# 入门演示

`getting-started/` 是可直接打开的独立清单，包含三条意见：

- 调整按钮对齐：配一张原创的简单表单示意图。
- 让空白状态提示更清楚：配一张小尺寸提示卡片，可体验原图放大。
- 核对操作说明：纯文字意见，预设为已完成，可点击复选框重新打开。

运行程序后从清单菜单选择“打开清单…”，打开 `getting-started/checklist.json`。先复制整个 `getting-started` 文件夹再试用，可以保留原样本；图片随文件夹一起搬迁。

图片是 `tests/SyntheticData.cs` 使用 WPF 几何图形、颜色和系统字体绘制的原创示意图，不是任何真实项目的截图，也没有第三方图像素材。清单文字、状态、ID、时间均为演示数据。图片和示例随仓库采用同一许可。

运行 `scripts/run-tests.ps1` 会在该次 `artifacts/tests/<唯一目录>/generated-demo/` 中重新生成一份演示清单，不修改这里的文件。生成图的文件名采用内容哈希，因此不同 Windows 字体/渲染环境可能生成不同字节；清单中的素材哈希会与当次图片一致。
